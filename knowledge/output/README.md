# Output

Generated deliverables that answer a specific `query` (see `.claude/rules/knowledge-wiki-ops.md`): reports, comparison tables, slide decks (Marp), one-off analyses -- things built *from* the wiki for a specific ask, not general knowledge that belongs in `wiki/`. If a query's answer is itself generally useful, file it into `wiki/` instead (an ingest); put it here only when it's a point-in-time deliverable for one ask.

Empty by default -- nothing here until a query produces a deliverable worth keeping.
