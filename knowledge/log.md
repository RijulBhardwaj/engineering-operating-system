## [2026-11-24] ingest | registry: cli-anything added, corrected what it actually is

User flagged `https://github.com/HKUDS/CLI-Anything` as "most important, implement this right now," framed as "most apps are made for human clickable, you can now use them to the fullest." Researched via web-fetch before installing: CLI-Anything is the opposite of that framing -- it generates structured Python CLI wrappers ("harnesses") around an app's real backend/API (headless LibreOffice/Blender/Godot, or a documented SaaS API with credentials), specifically to let an agent call JSON-structured commands instead of screenshot-clicking. It cannot add click-access to an arbitrary GUI-only app with no wrappable backend. Corrected this to the user before installing, then installed both pieces: the Claude Code plugin (`claude plugin marketplace add HKUDS/CLI-Anything` + `claude plugin install cli-anything@cli-anything`) and the Python `cli-anything-hub` package (`pip install --user cli-anything-hub`, confirmed working via `cli-hub --help`: `can`/`info`/`install`/`launch`/`list`/`matrix`/`previews`/`search`/`uninstall`/`update`). Registered as `cli-anything` in `registry/tools.yaml` alongside the existing `egm`/`obscura` entries, with a `decision` field flagging that harness generation needs a frontier model and that service-backed harnesses using real credentials have no built-in scoping guidance -- scope those manually per `security.md` before wrapping any SaaS API.
