# Engineering Standards & Patterns

Per-domain detail (API design, database design, architecture patterns, AI/ML engineering, infrastructure, reliability) goes here *when a real project generates it* -- not pre-populated with generic content nobody asked for. `.claude/rules/` holds the standards that apply right now; this directory is where depth accumulates project by project.

Empty category folders aren't tracked by git until they have content -- that's intentional, not an oversight.
